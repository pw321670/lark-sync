# 飞书 OAuth 配置

## 飞书应用需要的基础信息

在飞书开放平台准备：

- `App ID`
- `App Secret`
- 用来接收同步内容的根文件夹 token
- OAuth 回调地址

## 推荐回调地址

```text
http://127.0.0.1:3333/callback
```

注意：

- 要和插件设置里的 `redirectUri` 保持一致。
- 本地开发时建议优先使用 `127.0.0.1`，不要混用成 `localhost`。
- 如果飞书后台和插件设置里的地址不一致，授权会直接失败。

## 建议权限

至少确认飞书应用具备当前同步链路需要的文件读写权限。具体权限名称以飞书后台当前版本为准，但要覆盖：

- 读取文件夹内容
- 创建文件夹
- 上传文件
- 删除或覆盖同名文件时需要的文件管理权限

## 插件侧配置顺序

1. 填写 `App ID`
2. 填写 `App Secret`
3. 填写飞书根文件夹 token
4. 确认 `redirectUri`
5. 完成授权
6. 再执行同步

## 一个容易忽略的问题

如果你在插件加载后又改了 `App ID`、`App Secret` 或 `redirectUri`，授权对象也要跟着更新。当前代码已经在配置更新后重新初始化 OAuth，避免继续拿旧配置跑授权或刷新 token。
